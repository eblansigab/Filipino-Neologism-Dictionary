# Decision Log

## 2026-10-13 — Preserve raw data

Decision:
Raw spreadsheet values will not be modified automatically.

Reason:
The original spelling and source wording must remain available for historical
and linguistic review.

## 2026-10-13 — One row per meaning

Decision:
A word with multiple meanings will use multiple entry records.

Reason:
This prevents several unrelated definitions from being stored in one cell.

## 2026-10-13 — No AI features

Decision:
Search and analysis will use deterministic programming techniques.

Reason:
The project is intended to teach foundational data engineering and classical
computational linguistics.
