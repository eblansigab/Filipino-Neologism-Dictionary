# Methodology

## Data Collection

Entries are manually transcribed from identifiable dictionaries, books,
articles, websites, and other linguistic references.

## Transcription

The original spelling, definition, and etymological explanation are preserved
as closely as practical. Corrections are not silently applied.

## Source Recording

Every entry should identify its source. Page numbers should be included in the
notes when the source is a printed work.

## Verification Status

- verified: Confirmed through a reliable source
- unverified: Recorded but not sufficiently confirmed
- disputed: Sources disagree or the etymology is uncertain

## Data Processing

Raw data is never overwritten by the pipeline. Python creates a separate
processed dataset containing standardized fields used for searching and
analysis.

## Search Normalization

Future normalized search fields may use lowercase text and standardized
whitespace. These fields will not replace the original headword.
